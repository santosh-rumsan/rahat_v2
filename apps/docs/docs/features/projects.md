# Projects

The Projects module manages all humanitarian relief and development projects within Rahat.

## Project Grid

Projects are displayed as cards in a searchable grid. Each card shows:

- Project image and name
- **Status badge**: Active, Planning, or Completed
- Target location / context (e.g., earthquake relief, flood recovery)
- Number of **beneficiaries** enrolled
- **Budget** allocated to the project

Use the search input to filter projects by name.

## Project Statuses

| Status | Meaning |
|--------|---------|
| **Active** | Ongoing — distributions and enrollments are open |
| **Planning** | Not yet started — setup phase |
| **Completed** | Distributions finished |

## Adding a Project

Click **Add New Project** to create a new project. Required fields include:

- Project name and description
- Target location
- Budget allocation
- Projected beneficiary count

## Example Projects

Rahat v2 is designed for Nepal-based disaster response contexts. Sample projects in the system include:

- Nepal Earthquake Relief
- Flood Recovery – Terai
- Urban Food Security
- Drought Response – Karnali
- Landslide Recovery – Sindhupalchok
- Winterisation Support
