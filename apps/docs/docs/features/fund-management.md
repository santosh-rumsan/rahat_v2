# Fund Management

The Fund Management module gives finance teams a complete view of the treasury — total funds, project allocations, and transaction history.

## Treasury Overview

Four summary cards at the top of the page:

| Card | Description |
|------|-------------|
| **Treasury Balance** | Total funds held across all accounts |
| **Total Allocated** | Funds committed to active projects |
| **Total Spent** | Funds disbursed to beneficiaries and vendors |
| **Unallocated** | Funds in treasury not yet assigned to a project |

## Project Allocations

A table listing each project with:

- Project name
- Allocated amount
- Amount spent
- **Progress bar** showing spend vs. allocation

This lets finance staff quickly identify over- or under-spending per project.

## Recent Transactions

A chronological log of all financial events:

| Column | Description |
|--------|-------------|
| Transaction type | Deposit, transfer, disbursement |
| Amount | Value of the transaction (USD) |
| Project | Project the transaction is associated with |
| Date & time | When the transaction occurred |

## Distributing Funds

Click **Distribute Funds** to allocate money from the treasury to a specific project or initiate a disbursement to beneficiaries.

:::note
Only users with the **Finance** or **Admin** role can access Fund Management.
:::
