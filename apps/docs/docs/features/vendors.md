# Vendors

The Vendors module manages the suppliers and merchants who participate in Rahat distributions by accepting and redeeming beneficiary tokens.

## Vendor Table

Vendors are listed in a searchable table with the following columns:

| Column | Description |
|--------|-------------|
| **Name** | Vendor business name |
| **Type** | Category of goods/services offered |
| **Contact person** | Primary point of contact |
| **Phone** | Contact phone number |
| **Projects** | Number of active project assignments |
| **Status** | Active, Inactive, or Pending |

Use the search input to filter vendors by name.

## Vendor Types

- Food & Groceries
- Construction Materials
- Healthcare
- Agriculture
- Logistics
- Technology
- Clothing & NFI (Non-Food Items)

## Vendor Statuses

| Status | Meaning |
|--------|---------|
| **Active** | Enrolled and accepting token redemptions |
| **Inactive** | Not currently participating |
| **Pending** | Registration submitted, awaiting approval |

## Adding a Vendor

Click **Add Vendor** to register a new vendor. Provide their business details, type, and contact information. After registration the vendor status will be **Pending** until approved by an Admin or Manager.

## Vendor Actions

Each vendor row has a **more options** menu (⋯) with actions for editing details, changing status, or viewing transaction history.
