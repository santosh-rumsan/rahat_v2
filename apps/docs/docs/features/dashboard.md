# Dashboard

The Dashboard is the landing page of Rahat v2. It provides a real-time overview of the platform's key metrics and recent activity.

## Key Metrics

Four stat cards are shown at the top of the dashboard:

| Metric | Description |
|--------|-------------|
| **Total Projects** | Number of active and completed projects |
| **Beneficiaries** | Total individuals registered across all projects |
| **Total Budget** | Combined budget across all active projects |
| **Distributions** | Number of aid distributions completed |

Each card displays a trend indicator showing change since the previous period (e.g., "+3 this month", "+840 this month").

## Recent Projects

A table listing the most recently active projects with:

- Project name
- Status badge (Active, Planning, Completed)
- Number of beneficiaries
- Allocated budget

## Budget Utilisation

A visual progress bar showing:

- **Allocated**: portion of total budget committed to projects
- **Remaining**: unallocated treasury funds

## Recent Activity

A chronological feed of system events including fund transfers, project updates, beneficiary registrations, and distribution completions.
