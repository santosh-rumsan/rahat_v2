# Services

The Services module displays and configures the communication and distribution services used to reach beneficiaries.

## Available Services

### SMS Service

Provider: **Sparrow SMS**

Used for bulk notifications, OTP delivery, and two-way messaging with beneficiaries.

| Metric | Description |
|--------|-------------|
| Messages sent | Total SMS dispatched |
| Delivery rate | Percentage successfully delivered |

**Features:**
- Bulk messaging
- OTP delivery
- Two-way SMS
- Delivery reports

---

### IVR Service

Provider: **Ncell IVR**

Interactive voice response for automated calls — useful for beneficiaries with limited literacy or smartphone access.

| Metric | Description |
|--------|-------------|
| Calls handled | Total IVR calls completed |
| Average duration | Mean call length |

**Features:**
- Automated call flows
- Multi-language support
- Balance enquiry
- Status check

---

### Token Service

Provider: **QR / NFC tokens**

Digital vouchers issued to beneficiaries for redemption at enrolled vendors.

| Metric | Description |
|--------|-------------|
| Tokens issued | Total tokens distributed |
| Redemption rate | Percentage of tokens redeemed |

**Features:**
- QR code tokens
- NFC support
- Vendor redemption
- Expiry management

## Configuring a Service

Click **Configure** on any service card to update provider credentials, messaging templates, or distribution settings.
